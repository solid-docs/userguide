# Notepad

A notepad is a page of lines of text stored in your pod. Several people can write in the same notepad. Each person's lines are shaded in that person's colour, shown next to their name below the text.

![A notepad with three lines](/img/ug-views/notepad.png)

## Create a notepad

Creating a notepad needs the **Power user** user type. Open the account menu, choose **Preferences**, and select **Power user** under **Level of user**. See [User Roles](/reference/user-roles).

1. Open the folder where it should live.
2. Click **Add**, then **New Notepad**.
3. Type a name (without spaces) and click **Create**.

The notepad appears in the folder. Click it to open it.

## Write

Click the first line and type. Press **Enter** to start a new line. There is no save button: each line is saved as you type, and it is there when you open the notepad again.

## Start another pad

**Start another pad** below the text offers to make a new notepad somewhere else in your pod. It is simpler to use **Add** > **New Notepad** in the folder you want.

## Who can write

To let other people read or write the notepad, use [Manage Access](/views/manage-access).
